# MLS Field Reference

## california_sold (RESO-standard field names)
- ClosePrice — final sale price
- ListPrice — asking price at time of contract
- DaysOnMarket — days from listing to contract
- LivingArea — finished square footage
- City, PostalCode — location fields
- BedroomsTotal, BathroomsTotalInteger — room counts
- PropertyType, PropertySubType — e.g. Residential, Condominium

## rets_property (IDX legacy field names)
- L_SystemPrice — current list price
- L_Keyword2 — bedrooms total
- LM_Dec_3 — bathrooms total
- LM_Int2_3 — approximate finished square footage
- L_City — city, indexed
- L_Type_ — property subtype (Condominium, SingleFamilyResidence, etc.)
- L_Status — listing status (Active, Pending, Withdrawn)
- L_Remarks — full free-text listing description
